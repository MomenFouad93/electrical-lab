#5763
Le fluide de barrage, maintenu à une pression supérieure à celle du produit (par exemple API Plan 53), entre par IN et sort par OUT en refroidissant les deux garnitures. Si la garniture intérieure s'use, c'est du fluide de barrage propre qui fuit dans le produit au lieu que le produit fuie vers l'extérieur.
O fluido de barreira, mantido a uma pressão maior que a do produto (por exemplo API Plan 53), entra por IN e sai por OUT, resfriando os dois selos. Se o selo interno se desgastar, é o fluido de barreira limpo que vaza para o produto, em vez de o produto vazar para fora.
隔离液压力保持高于产品压力（例如 API Plan 53），从 IN 口进入、从 OUT 口流出，同时冷却两道密封。如果内侧密封磨损，漏进产品的是干净的隔离液，而不是产品漏到外面。
Затворная жидкость под давлением выше давления продукта (например, API Plan 53) входит через IN и выходит через OUT, охлаждая оба уплотнения. Если внутреннее уплотнение изнашивается, в продукт протекает чистая затворная жидкость, а не продукт наружу.
Ciecz barierowa utrzymywana pod wyższym ciśnieniem niż produkt (np. API Plan 53) wpływa przez IN i wypływa przez OUT, chłodząc oba uszczelnienia. Gdy wewnętrzne uszczelnienie się zużyje, do produktu przecieka czysta ciecz barierowa, a nie produkt na zewnątrz.
A terméknél nagyobb nyomáson tartott zárófolyadék (például API Plan 53) az IN csonkon lép be és az OUT csonkon távozik, mindkét tömítést hűtve. Ha a belső tömítés elkopik, tiszta zárófolyadék szivárog a termékbe, és nem a termék szivárog ki.
El fluido barrera, a mayor presión que el producto (por ejemplo API Plan 53), entra por IN y sale por OUT, refrigerando ambos sellos. Si el sello interior se desgasta, es barrera limpia lo que fuga hacia el producto, en lugar de que el producto fugue hacia fuera.
