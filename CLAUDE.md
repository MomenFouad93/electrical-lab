# Electrical training lab: handoff for the next session

Read this first. Continue from the current state; do not restart or re-scan the project from scratch.

## What it is
An offline training web app for maintenance technicians: Bench (circuit simulator with meters; views Panel / Plant / Line), Projects (ready projects: panel + process plant + PLC ladder, pharma water PW/WFI, packaging line), Programming (PLC ladder editor, its own tab), LOTO, PCB repair, Inspect, Guide. 9 languages. Owner: Momen (writes Egyptian Arabic, wants short answers; a team of reviewer agents + a QA pass before every delivery; never deliver links or buttons that do not work).

- Live (what users open and install): https://momenfouad93.github.io/electrical-lab/
  - Never rename the repo, the folder or the URL: installed phones keep this address.
  - Users get updates automatically: the service worker loads the page network-first, and the app checks `version.json` on open / return and shows "Update now".
  - Never clear or rename localStorage keys (`ellab.*`) without a migration.
- Source of truth: `source/` in this repo (copy of the lab folder). Repo root = built web app. `electrical-lab.html` at the root = the same app as one offline file (for the company laptop).

## Build, test, deploy
```
cd source
node build.js                        # -> dist/electrical-lab.html (+ dist/build.txt = build stamp)
node tools/pwa.js                    # -> pwa/ : index.html with hash CSP, sw.js, manifest, icons, version.json
node test/t_plant.js; node test/t_proj.js; for t in test/t_*.js; do node $t; done   # known old failures: t_inst.js (1 megger line), t_core.js (stale test: EL.models === EL.defs)
node test/ui_scratch.js d|m          # builds a tank project from scratch through the UI
for t in qa_projects qa_plant qa_ladder qa_bench qa_mobile qa_lang; do node test/$t.js; done   # QA click-through suites (known test notes: qa_plant "P1 number#5 / UV1 number#0 no effect" = props that only act on a local VFD pump or with flow)
node test/e2e_pwa_security.js        # serves pwa/ on :8099: CSP, offline, update bar, hostile files
node test/ui_proj.js d|m             # screenshots to /tmp/claude-0/shots
node test/t_water.js; node test/t_stilmas.js (slow, ~3 min); node test/t_line.js; node test/ui_water.js d|m; node test/ui_line.js d|m; node test/ui_prog.js d|m
MSG="..." NOTE="..." REPO=<path of this repo clone> ./tools/deploy.sh
```
Playwright: `require('/opt/npm-tools/node_modules/playwright')` in the cloud sandbox.
i18n: strings are `[English, Arabic]` pairs; other languages come from `i18n/keys.json` (append new keys, keep ids) + `i18n/work/cNN.txt` blocks (`#id` + 7 lines fr, pt, zh, ru, pl, hu, es), then `node tools/i18n_build.js --check` and `node tools/i18n_build.js` (writes src/i18n_data.js). Extract new pairs with the logic in `tools/i18n_extract.js` (do not run it in place: it renumbers ids).

## Code map (source/src)
- `core.js` circuit solver + `EL.tick` (also steps the plant). `parts_*.js` part models, `parts_h.js` 3-wire 0-10 V transmitter TXV.
- `water.js` pharma water on top of plant.js: pipe DN/ID tables + Darcy friction (pipes get dn/mat/len/loop), valve Kv by DN and type, pump curves H0-kQ² (qbep/hbep presets), local VFD + level control for pumps (local, spd, lvt/lon/loff, stk, psl trip), water-quality vector (cond, hardness, Cl2, TOC, SiO2, bacteria, endotoxin, SDI, CO2, antiscalant) through every unit, units SOFT DOSE EDI UV STILL DIV QA POU, USP Stage 1 / Ph. Eur. PW tables, spec checks (bacteria = action level, WFI <70 °C = control limit), tank fill/empty ETA, loop velocity / Re / dead-leg checks. Training speed-ups: bacteria growth 24x, chlorine damage ~10000x.
- `line.js` packaging line (Bench > Line view, `circuit.line`): 0.5 m grid, elements SRC CONV CURVE GAP CW SER TE REJ BUF TURN TWIST CP EXIT, carton orientations fa/fl/edge/end, `LN.checks` (guides, curve fit, stability, V-curve, pitch, checkweigher dwell, turner gap, reject after the last inspection), `LN.step` (buffers per element, reject confirmation via air, N rejects in a row stop, escaped bad carton stops the line, case change pause). UI `ui/line_ui.js`.
- `plant.js` process simulator: units (SUPPLY, TANK, PUMP, VALVE, SOLV, CHECK, FILTER, RO, HX, PT, PS, FS, TT, PG, FM, JUNC, DRAIN), linear hydraulic net per tick, links to panel parts by tag (pump.motor, tank.lt / sw[] / htr / tt, PT.tx, PS.sw, FS.sw, TT.tx, SOLV.sol). Motors get `state.pl` (load) from linked pumps.
- `ladder.js` LAD runtime for PLC24/PLC24R when `props.mode === 'ladder'`, program JSON in `props.lad`; `LD.check` static checks, `LD.why` rung diagnosis, sanitiser for files.
- `projects.js` ready projects (tank star-delta PLC, booster VFD, RO + heat exchanger, packaging line (view 'line'), pharma water city→PW→WFI (plant only, local VFD pumps))
- `stilmas` ready project (2026-11-23, Momen asked to have it on the live link): two-pass RO PW station with the CB2 HMI and hot sanitisation. Company names, job and drawing numbers are kept out of the repo; test: test/t_stilmas.js. A project may have no `circuit` and/or a `line`.
- water.js extras: TEMP (feed heater/cooler, set/san °C, kwh/kwc duty limits), DEG (membrane degasser), CTRL (station HMI: prod / sanit / dist buttons via data-act, hot-sanit sequence: dclose/dopen valve tags, hold min, stank), pump `grp` ('prod'|'dist') + `sanrun`, DIV `tmax` (also diverts during sanit), RO `hot` (sanitisable to 85 °C), TANK `ins` (insulated). Dead legs only checked on loop pipes.
- `cycles.js` station cycles on the CTRL (HMI) unit, generic by CTRL props (stank, ptank, drains, inlet, ffv, hp1, hp2, qin/qsoft/qpw design flows): start-up from empty, drain all / PW only, loop flush, RO fast flush, whole wash, hot sanit RO / tank+loop / whole. Steps = {n, go, tick, done, est, end}; progress in CTRL state as numbers (cyN, cyI, cyT, cyTs, csN actual, ceN estimate at step start, cpN estimate at cycle start, cyKh/cyKc kWh, cyDr/cyPo litres) so it survives a save; changed props are snapshotted in state._snap and put back. Estimates: Torricelli with K = 1 + 1.5·f·L/D, exchanger heat/cool with full duty then exponential approach. Loop hot sanit = CTRL `lsan` + TEMP `mode:'loop'` (heats only in lsan, otherwise only cools). UI `ui/cycles_ui.js` (#plCyc panel in the plant host, bottom sheet on phones above the dock). Bench speed 300x steps 1 s (process-only projects). Test: test/t_cycles.js (~2 min), test/ui_cycles.js d|m.
- `circuit.js` serialize / deserialize (validates and caps imported files; includes `plant`).
- UI: `ui/projects_ui.js` (Projects tab, Panel/Plant/Line switch), `ui/water_art.js` (drawings of the water units), `ui/line_ui.js`, Programming tab = `#v-prog` (ladder_ui renders into `#ladHost` there), `ui/plant_ui.js` + `ui/plant_art.js`, `ui/ladder_ui.js`, `ui/update.js` (SW register + update bar), rest as before.

- Mechanical tab (`#v-mech`): `src/vendor/three.js` = three.js r170 module converted to a classic script that sets `EL.THREE` (`node tools/vendor_three.js <three.module.min.js>`, MIT licence in src/vendor). `src/mech.js` registry (`EL.mech.add` components, `EL.mech.addBuild` workshop projects, categories). Data: `src/mech_*.js` (valves, actuators, pumps, motors, transmission, bearings, seals, tools, fasteners, process; 63 items) in the format of `tools/MECH_FORMAT.md` (shapes in cm, axes, explode offsets, steps, anim, quiz). `src/mech_builds.js` = workshop bases + slots with right/wrong options and reasons. `ui/mech3d.js` builds meshes (creased normals for lathe shapes) and the viewer (orbit/pinch, explode, cutaway with section caps, pick, labels, operate, slot labels + drop target). `ui/mech_ui.js` = Library / Assemble game / Workshop (drag-drop or tap) / Quiz, localStorage `ellab.mech`. Check renders: `node tools/mech_shot.js <id>|--all|--check` (PNGs in /tmp/mech).
- Real look on the bench: `ui/real_art.js` (`EL.real[type]` drawings with the same footprint and pins; shared gradients in a hidden svg), DIN rail / wire duct / mounting plate parts (RAIL40, RAIL60, DUCTH, DUCTV, PLATE; devices dropped near a rail clip on: `ed.snapRail`), phase colours IEC or red-yellow-blue (`ellab.phcol`), auto offer to wire the other phases after one (`ed.suggestPhases`, off with `ellab.autoPhase`=off), Display menu (#btnLook, `ellab.real`).
- `ui/panels.js`: fold handles (`.fold-h`) on Bench, PCB, Programming and Mechanical; state per view in `ellab.panels` ({bench:{l,r}, pcb, prog, mech}; the old {l,r} format is migrated).

## Security
- `tools/pwa.js` injects a hash-based CSP (only the shipped inline script runs; network only to self and api.anthropic.com for the optional AI photo check). If you add an inline script or a new external host, the CSP must allow it, then rerun `test/e2e_pwa_security.js`.
- Imported files go through `EL.deserialize` / `EL.plant.sanitize` / `EL.ladder.sanitize` (size caps, markup stripped). Keep new string fields escaped when rendered.
- The repo is public (free GitHub Pages): no company data, names or secrets in it.
